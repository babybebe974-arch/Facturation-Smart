# Facturation Smart — Smartdesignforyou

Application de devis, factures, bons de livraison, bons de crédit et dépôts-vente pour Smartdesignforyou Ltd.

- Installable sur Android et PC (PWA) : ouvrir la page dans Chrome → « Installer l'application ».
- Archivage automatique des PDF dans Google Drive (dossier « Factures Smart ») et registre Google Sheet, via un script Apps Script.
- La clé secrète du script se saisit dans l'onglet SAUVEGARDE de l'app ; elle n'est jamais écrite dans ce dépôt.
